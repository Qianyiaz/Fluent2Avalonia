# Fluent2Avalonia

Fluent2Avalonia is a small library of Fluent 2-inspired controls and icons for [Avalonia UI](https://avaloniaui.net/).
It is designed to help Avalonia apps build familiar navigation experiences and use Fluent-style symbol icons.

## What’s included

- **NavigationView** with menu and footer items, page navigation, back navigation, and optional page caching.
- **Symbol icons** with a `Symbols` enum and an included symbol font.
- **Fluent2ControlsTheme**, which brings the library’s control styles and resources into an Avalonia application.
- **A demo app** in `samples/Fluent2Avalonia.Demo` for trying the controls.

## Try the demo

Install the .NET SDK required by the demo project, then run:

```shell
dotnet run --project samples/Fluent2Avalonia.Demo/Fluent2Avalonia.Demo.csproj
```

The reusable libraries are in `src/Fluent2Avalonia` and `src/Fluent2Avalonia.Icons`.
